# Public-method research library for the seven-agent feasibility studio

**Compiled:** 2026-11-15. **Purpose:** reusable analytical techniques, not investment evidence for any particular project. Public primary-source examples are summarized, not copied wholesale.

## Read this before using the library
- [PUBLIC_CASES.md](PUBLIC_CASES.md): 18+ disclosed case examples / method publications across Goldman Sachs, McKinsey, Morgan Stanley, JLL, Anthropic and Bain Capital, with attributable URLs and limits on transferability.
- [RESEARCH_STANDARD.md](RESEARCH_STANDARD.md): explicit research workflow, per-asset reconciliation, counterarguments, source integrity, independent challenge, and the V4.0-only firewall.
- [AGENT_EVALUATIONS.md](AGENT_EVALUATIONS.md): reproducible agent quality tests for coverage, calculations, evidence discipline, contradictions and transfer-of-learning.
- Specialist agent configurations in `.claude/agents/` point here; the Head of Market Research uses the cross-agent protocol.

**IMPORTANT EVIDENCE FIREWALL:** The current Aquaverse RID V4.0-to-V5.0 study explicitly restricts project evidence to the V4.0 sponsor document. This library can inspire questions, work plans, audit tests and report structures, **but cannot supply new market facts, cost benchmarks, demand rates, returns, comparables, vendor specifications or claims about Aquaverse** until the user changes the evidence scope. In this mode, tag sourced figures SPONSOR / CALCULATED / UNKNOWN according to the charter, and cite the V4.0 location.

No agent represents, speaks for, or has proprietary access to its named institution. Firm-style means independent adaptations of public descriptions; not an exact or endorsed firm process.

**Not exhaustive:** Public deal records and case libraries are vast, unevenly disclosed and change over time. The examples here are a relevant sampled foundation, not every project undertaken by the firms. Public client stories are often promotional; never infer causation, unpublished financial results, or investment suitability from them.
